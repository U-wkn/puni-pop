# 🫧 PUNI POP!（プニポップ）

**かわいくて爽快なストレス解消ゼリーゲーム**

ぷにぷにした感触、物を壊す爽快感、ASMRのような音、癒やし、コンボ連鎖の5つの要素を組み合わせた、ブラウザでいつでも遊べるリラクゼーションゲームです。時間制限やゲームオーバーはなく、好きなだけ自由に遊べます。

---

## 🎮 遊び方

ブラウザで `index.html` を開くだけですぐに遊べます！（スマホ・PC両対応）

### 3つのプレイスタイル（モード切り替え）
1. **🔮 ぷにぷにモード (Squish)**
   - 触ると「ぷにっ」、指を離すと「ぽよん」。
   - ドラッグしてびよ〜んと引き伸ばしたり、こねたり、弾ませたりして存分に触感を味わえます。
   - 割れないので、のんびり癒やされたいときに最適です。
2. **💥 ポップ！モード (Pop)**
   - タップやクリックで「パチッ！」と気持ちよく弾け飛びます。
   - 破裂時の衝撃波で周囲のぷにも巻き込んで、ドミノ倒しのようにド派手に大連鎖！
   - スワイプで画面内のぷにを連続でなぞって一気に割ることもできます。
3. **✨ フリーモード (Free)**
   - 短いタップでポップ、長押しやドラッグでぷにぷに。両方の快感をシームレスに楽しめます。

### 特殊機能＆ボタン
- **➕ ぷにを追加**: 画面上部から新しいぷにがぽよんと降ってきます。
- **⚡ 連鎖バースト**: 画面内のぷにを一斉に連鎖ポップさせる爽快必殺アクション！
- **🔄 リセット**: 画面をきれいにリフレッシュして、新しいぷにを再配置します。
- **🔊 サウンド (SE) / 🎵 癒やしBGM**: いつでもワンタップでON/OFF切り替え可能。
- **⚙️ 設定**: 全体音量、効果音音量、BGM音量、自動補充のON/OFFを細かくカスタマイズできます。

## 🎧 ASMR音響システム

Web Audio APIによる完全プロシージャル（純粋合成）サウンドエンジンを搭載。外部音声ファイルへの依存がなく、超低レイテンシで再生されます。

- **ぷにっ**: 柔らかく瑞々しいウォータードロップ＋ゼリーの押し込み音
- **ぽよん**: 指を離したときの弾力あるスプリング音
- **パチッ**: シャンパンの泡やプチプチが弾けたような爽快な破裂音
- **ポポポン！**: 連鎖するたびにドレミファソラシドと音階が上がっていくマリンバ／クリスタルベル音
- **癒やしのアンビエントBGM**: 水中や雲の上にいるようなリラックスできるシンセパッド
